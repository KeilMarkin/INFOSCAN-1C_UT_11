Расширение предназначено для интеграции измерительного устройства ИНФОСКАН с конфигурациями 1С Управление Торговлей 11, Комплексная Автоматизация, ERP.
Расширение может работать в двух режимах:
1. Инфоскан выступает в качестве сервера, а 1С в качестве клиента. Для этого Используется форма "Опрос устройства" там в режиме реального времени 1С опрашивает устройство, есть ли на нем измерения и если есть то выводит в таблицу.
Номенклатура сопоставляется по штрихкоду через поиск в регистре "Штрихкоды номенклатуры".
2. 1С является сервером, а устройство клиентом. Для этого необходимо опубликовать web-сервис расширения и прописать его в настройках инфоскана. В момент измерения инфоскан отправляет данные в 1С.

Измерения аписываются согласно настройкам указанным в расширении. Каждое измерение может храниться в реквизите номенклатуры, реквизите упаковки, дполнительном реквизите номенклатуры, дополнителньом сведении номенклатуры.
